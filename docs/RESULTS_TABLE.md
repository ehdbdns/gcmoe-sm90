## 结论

1. **ECO 在四档 batch 全部最快**，相对 random 基线省 7.0–8.6%。
2. **ECO 的 ms 优势来自 M 块数更少**（BS=128: 33 vs 40；BS=256: 42 vs 50），
   而非 pull —— quota 切分把 token 集中到更少槽位，减少 GEMM 调用。
3. **TMA 让所有臂全面提升**，batch 越大收益越大（ECO −6.2% ~ −13.8%）。
4. **冗余度对 rank 级 IR 无系统性影响**：四组最忙 rank 都在 775k–786k（1.4% 波动），
   与 IR 差异同量级。冗余度优化的是槽级分布（`ir_slot`）。选 extra=8 因 ms 最优。
5. **EPLB 把 rank 极差压掉一个数量级**（random 41k–440k → eplb 9k–50k）。
