## 线性模型（用各 valid 的均值做最小二乘）

```
L1:  t ≈ 15.01 + 0.536 × valid     (µs)
L2:  t ≈  7.88 + 0.241 × valid     (µs)
```

即每多做 8 行：L1 多 4.3 µs、L2 多 1.9 µs。

这印证了 ECO 的代价函数形状是对的：**耗时对 valid 是仿射的（固定开销 + 每行线性）**，
不是"一个块等于一个常数"。所以 `wb`（每块固定开销）和 `token` 项（每行）确实都要保留。

## 读方差时的两个注意点

1. **组内方差很小，组间方差很大。** 同一 valid 内 CV 只有 1.6%–6.1%，
   而把全部 valid 混在一起的方差是 91.1（L1）/ 18.4（L2）。
   ⇒ **valid 是耗时的主要解释变量**，同 valid 下的抖动基本是噪声。
2. **1 µs 时间戳分辨率的下限。** 所有时长都是整数 µs，
   一个恒定值 d 的量化方差是 `1/12 ≈ 0.083 µs²`。实测组内方差 0.28–0.69，
   是量化下限的 3–8 倍，说明存在真实的微小抖动（L1 尤其明显：
   valid=48 的方差 1.877 是最大的，但 n 只有 18，样本少）。

## 复现

```bash
cd .../t18_abstrace/docs/abstrace
python3 - <<'PY'
import csv, collections, statistics
rows=[r for r in csv.DictReader(open('AT256_eco_mbclaim_rank0_full.abstrace_rank0.csv'))
      if r['kind']=='gemm']
by=collections.defaultdict(list)
for r in rows: by[(r['phase'],int(r['valid']))].append(float(r['dur_us']))
for (p,v),d in sorted(by.items()):
    m=statistics.mean(d); var=statistics.pvariance(d)
    print(f'L{p} valid={v:3d} n={len(d):4d} mean={m:6.2f} var={var:7.3f}')
PY
```
