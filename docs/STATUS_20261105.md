## 与立项时规格的差异（都已在本目录文档里写明）

1. `sources/gc-moe-main` 不存在 → 用本目录 `source/`；SM90 原先**完全没有** ECO。
2. role 编号用 5（role 4 是 shared expert）。
3. 线程 256（不是 576），`P` 的循环全部 grid-stride。
4. plan 与 routed role 争 SM：routed grid 必须让出**一整块** SM（留半个仍死锁）。
5. two-hop 关闭：EP8 完全图，一跳必然可达；SM100 在 ≤32 rank 也是 0 轮。
6. `eco_state` 用 int32（SM90 DSL 没有 Uint16）。
7. wb/wa 未标定，用 0/0（token 主导，等价于 SM100 的 `OBJECTIVE=token`）。
