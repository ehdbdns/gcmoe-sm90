## 语义与校验

- 几何：H5120、I2304、M64、6 dispatch SM、1 个 fused shared expert；各源 rank 独立输入 128 token，合计 1024，顶 6，合计 6144 路由项。
- 两次分别跑 RR 与 ECO，输入 SHA256 逐 rank 相同（`se_perfetto.py` 里 `input_sha256` 校验通过），两臂的副本归属布局也逐 rank 相同。
- 采样：`sample 0/1/2` 对应 replay epoch `9/10/11`，每 rank 三次；每样本全局路由项合计均校验为 6144。
- 每段均带 `sample`、`epoch`、`rank_tokens`、`m_blocks`、`first_cta_raw_us`、`last_cta_raw_us`，由该次 replay 的实际 CTA 全局时钟换算，未补画区间。
- 分轨：dispatch（含 count exchange、local count exchange、pull token）、shared expert L1、shared expert L2、routed kernel、wait token、routed GEMM（第一个 CTA 开工到最后 CTA 完工）、combine；ECO 另有 ECO plan 与 dispatch admission。
- `se_perfetto.py` 的断言全部通过（role 几何唯一、kernel 数 == replay 数、CTA 时钟与 CUPTI 一致、count exchange/pull 落在 dispatch 内、routed CTA 时钟与 CUPTI 一致）。
