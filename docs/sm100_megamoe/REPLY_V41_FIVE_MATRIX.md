- 首个失败阶段：**stats 窗口的 logical top-6 / gate 权重摘要**，八个 rank 均已不一致；不是 measure 阶段才出现，也不是放置迁移失败。
- `controlled_replay` 全为 true：各臂的 replay IDs、replay 权重、batch order 摘要都与同档 Mega 的 logical 记录逐步一致；measure 窗口按 plan 聚合后的每层全局 routed token 数均为 `BS × 6`，与 Mega 逻辑需求逐元素相等。
- 但各臂自身模型产生的 `logical_ids` / `gate_weights` 与 Mega 不同，measure 的原生 top-1 `native` 也不同，因此 `native_token_equal` 与 `native_gate_equal` 全为 false。

- 仅保留整阶段摘要，未逐步保存 native/gate 摘要，因此不能从本交付定位“第一个不同的 decode step”；没有把窗口摘要差异误报成某个具体步号。
